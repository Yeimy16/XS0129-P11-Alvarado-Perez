## Conjuntos de Datos Utilizados

El análisis se realiza empleando los siguientes datasets nativos de R:
* `airquality`: Datos sobre la calidad del aire en Nueva York en 1973.
* `mtcars`: Características y rendimiento de 32 automóviles.
* `iris`: Medidas morfológicas de tres especies de flores.
* `ToothGrowth`: Datos de crecimiento dental en conejillos de indias.
